## 🎯 اهداف اصلی بازنویسی سیستم

1. **حذف کامل نرم‌افزار قدیمی صندوق (PTC POS):** جایگزینی با نرم‌افزار حسابداری/ERP جدید که دارای REST API اختصاصی است.
2. **استقلال از شرکت داده‌فا (Dadehfa):** حذف فایل‌های کامپایل‌شده‌ی باینری (DLLهای بدون سورس) و ساخت یک بک‌اند بومی، تمیز و استاندارد (پایتون / جنگو).
3. **حفظ کامل فرانت‌اند موجود (`mong_front`):** استفاده مستقیم از سورس‌کد Next.js 15 بدون نیاز به بازنویسی ظاهر سایت.
4. **توسعه موازی بدون توقف فروش (Zero-Downtime):** ساخت سیستم جدید روی ساب‌دامین موازی و تست کامل با درگاه و ERP جدید پیش از لانچ نهایی.
